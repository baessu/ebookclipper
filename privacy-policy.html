개인정보처리방침

eBook Highlight Clipper (eBook 하이라이트 추출기)

1. 개요

eBook Highlight Clipper(이하 "본 확장 프로그램")는 사용자의 개인정보를 수집, 저장, 전송하지 않습니다. 본 문서는 확장 프로그램의 데이터 처리 방식을 투명하게 안내하기 위해 작성되었습니다.

2. 수집하는 정보

본 확장 프로그램은 어떠한 개인정보도 수집하지 않습니다.

  • 사용자 계정 정보를 수집하지 않습니다.
  • 브라우징 기록을 수집하지 않습니다.
  • 쿠키 또는 추적 기술을 사용하지 않습니다.
  • 외부 서버로 데이터를 전송하지 않습니다.

3. 데이터 처리 방식

본 확장 프로그램은 사용자가 버튼을 클릭했을 때, 현재 열려 있는 웹 페이지에서 하이라이트 텍스트를 읽어 사용자의 클립보드에 복사합니다. 이 과정은 전적으로 사용자의 브라우저 내에서 로컬로 처리되며, 어떠한 데이터도 외부로 전송되지 않습니다.

4. 권한 안내

본 확장 프로그램은 다음 권한을 사용합니다:

  • activeTab: 사용자가 확장 프로그램 아이콘을 클릭한 현재 탭에서만 스크립트를 실행합니다.
  • scripting: 페이지에서 하이라이트 텍스트를 추출하기 위해 스크립트를 실행합니다.

5. 제3자 공유

본 확장 프로그램은 어떠한 데이터도 제3자와 공유하지 않습니다.

6. 변경 사항

본 개인정보처리방침은 변경될 수 있으며, 변경 시 본 페이지를 통해 공지합니다.

7. 문의

본 확장 프로그램에 관한 문의는 GitHub Issues를 통해 접수해주시기 바랍니다.
